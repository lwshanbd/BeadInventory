# STEP 08 - 性能与稳定性

## 目标

保证演示过程稳定、流畅、可重复，不因高负载崩溃。

## 输入

1. 已实现的 2D/3D 功能链路。
2. 真机性能观测数据（耗时、内存、卡顿点）。

## 输出

1. 后台化和缓存策略。
2. 分辨率自适应策略。
3. 稳定性兜底与错误恢复机制。

## 实施步骤

1. 任务调度优化：
   1. 图像匹配、体素化放在后台任务。
   2. 主线程仅做进度和最终渲染更新。
2. 缓存策略：
   1. 调色板 Lab 缓存。
   2. 体素切片中间结果缓存。
3. 内存控制：
   1. 大图分块处理。
   2. 3D 分辨率上限（超限提示降档）。
4. 失败兜底：
   1. 3D 处理失败可回退到 2D。
   2. 部分层失败时保留已完成层和总统计。

## 建议改动文件

1. `BeadInventory/Managers/Blueprint2DService.swift`
2. `BeadInventory/Managers/VoxelBlueprintService.swift`
3. `BeadInventory/Views/BlueprintCreateView.swift`
4. `BeadInventory/Views/BlueprintLayerPreviewView.swift`

## 完成定义（DoD）

1. 连续运行 20 次核心流程不崩溃。
2. 处理中可见进度状态和可取消操作。
3. 超大输入时有清晰降级提示，不直接卡死。

## 测试清单

1. 2D 大尺寸图（128x128 / 256x256）性能对比。
2. 3D 不同体素分辨率（低/中/高）性能曲线。
3. 扫描中断、后台切换、内存压力场景稳定性测试。

## 风险与回退

1. 风险：为了速度牺牲过多质量。  
2. 回退：提供“快速/标准/高质量”三档处理模式。
