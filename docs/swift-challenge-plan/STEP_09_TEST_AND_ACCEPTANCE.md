# STEP 09 - 测试与验收

## 目标

形成可复现的验收流程，确保提交前功能、稳定性、离线约束都达标。

## 输入

1. STEP 01-08 的全部实现。
2. 真实设备与测试样本（图片、实体物体）。

## 输出

1. 功能验收报告。
2. 离线合规清单。
3. 演示脚本和回归检查列表。

## 验收维度

1. 功能正确性：
   1. 2D 创建、统计、编辑、计划创建、库存扣减。
   2. 3D 扫描、分层、统计、计划创建。
2. 离线合规性：
   1. 飞行模式全链路可运行。
   2. 核心流程不依赖云服务。
3. 稳定性：
   1. 连续多轮测试无崩溃。
   2. 异常输入有可恢复提示。

## 详细测试步骤

1. 2D 测试：
   1. 准备至少 10 张不同风格图片。
   2. 逐张生成图纸并记录耗时、统计总量。
   3. 随机编辑格子，验证统计与计划结果一致。
2. 3D 测试：
   1. 准备 3 个实体（规则体/曲面体/多色体）。
   2. 完成扫描并导出分层图纸。
   3. 校验总统计与各层求和一致。
3. 回归测试：
   1. 原扫描页识别功能无回归。
   2. 项目归档/复制/合并/执行正常。
   3. 备份恢复后图纸项目数据完整。

## 建议验收表（可复制）

```text
[ ] 飞行模式下 2D 全链路可用
[ ] 飞行模式下 3D 全链路可用（LiDAR 设备）
[ ] 2D 图纸统计与项目统计一致
[ ] 3D 分层总量与汇总一致
[ ] 创建计划与库存扣减链路无回归
[ ] 连续运行 20 次无崩溃
[ ] 非 LiDAR 设备降级提示正确
```

## 交付物建议

1. 演示用样例图/样例物体说明。
2. 关键功能录屏（2D + 3D + 离线）。
3. 已知限制列表（设备、材质、分辨率上限）。

## 风险与回退

1. 风险：3D 在部分设备表现不稳定。  
2. 回退：提交版本优先确保 2D 完整可演示，3D 作为增强项保底演示。
